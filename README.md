# Tittow Panel

Fabric-Mod für **Minecraft Java 26.3**: Deine eigene Spielfigur läuft in deiner Mob-Farm herum
und schlägt Mobs, menschlich wirkend, ohne je den Mob-Bereich zu betreten.
**Numpad 8** öffnet im Spiel das **Tittow Panel**, dort schaltest du den Bot an und aus.

> Nur für deine eigene Welt oder deinen eigenen Server.

## Installieren und aktualisieren
1. [`aktualisieren.bat`](aktualisieren.bat) herunterladen (rechts oben auf „Download raw file“).
2. Doppelklick, und schon liegt die **neueste Mod** im Pumpcraft-mods-Ordner.
3. Bei jedem Update einfach wieder doppelklicken.

Die fertige Mod-Datei gibt es auch direkt unter [Releases → neueste](../../releases/tag/neueste).

Wie man die Mod im Spiel benutzt, steht in der [ANLEITUNG.md](ANLEITUNG.md).
